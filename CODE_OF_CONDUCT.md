# Code of conduct

Be respectful and constructive. Assume good faith, keep feedback about the
work and not the person, and welcome beginners.

Not acceptable: harassment, insults, discrimination, publishing someone's
private information, or sustained disruption of discussions.

Maintainers may edit or remove comments, issues and pull requests that break
these rules, and may block repeat offenders. Report problems by opening a
private security advisory on this repository or contacting the maintainer
through the profile linked from the repository.
